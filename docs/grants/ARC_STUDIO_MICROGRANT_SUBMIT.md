**Project:** Railguard Spend Gate

## Why this build

The grant scores real Arc mainnet USDC movement, meaningful Arc Studio usage, a working product, and potential to go further. Railguard already has settlement verification and failure-evidence infrastructure, but this round specifically requires a contract, tests, and app built in Arc Studio.

The smallest strong submission is therefore a focused agent-payment gate rather than porting the whole Railguard stack.

### Demo story

1. Agent proposes a USDC payment.
2. Railguard preflight checks the payment ID, recipient, per-payment cap, cumulative budget, and agent identity.
3. A valid payment executes through `RailguardArcGate` on Arc mainnet.
4. The app shows the confirmed transaction and remaining budget.
5. Reusing the same payment ID or exceeding policy is blocked.
6. Railguard records a reproducible evidence manifest for the successful mainnet payment.

## Exact execution order

1. Open Arc Studio and run the prompt in `docs/grants/ARC_STUDIO_BUILD_PROMPT.md`.
2. Keep the generated contract, tests, and app inside the same Arc Studio project.
3. Validate all contract tests on Arc testnet.
4. Export/push Arc Studio output into this repo under `labs/arc-studio-spend-gate/`.
5. Review the exported contract before mainnet use.
6. Deploy the reviewed contract to Arc mainnet (chain 5042) using the builder's own wallet/tooling.
7. Run one tiny real payment through the app/contract. Keep the value intentionally small.
8. Set the environment variables below and run the verifier.
9. Add the generated `evidence/arc-studio/manifest.json` and README to the repo.
10. Record a short walkthrough showing Arc Studio project, tests, live app, policy preflight, successful mainnet payment, explorer proof, and one blocked/replay attempt.
11. Submit the links on DoraHacks.

## Submission copy

### Project name
Railguard Spend Gate

### One-line description
A policy-enforced payment gate for AI agents on Arc: cap spend, stop replayed payment IDs, execute USDC, and leave verifiable evidence.

### Short description
Railguard Spend Gate is a focused Arc-native proof of Railguard's financial execution firewall. An authorized agent can execute a payment only when it passes identity, replay, per-payment, and cumulative-budget checks. The Arc Studio-built app performs preflight checks, executes a real USDC payment through the contract, and links the resulting Arc mainnet transaction as evidence.

### Why Arc Studio
The contract, tests, and app are built and iterated in Arc Studio. Arc Studio is used for the onchain contract workflow and application wiring; mainnet signing remains external as required by Arc Studio's production model.

### Potential to go further
This contract is the narrow onchain enforcement layer for Railguard's broader lifecycle: Intent → Authorize → Reserve → Execute → Observe → Reconcile → Evidence. The same policy/evidence model can protect x402, wallet, treasury, and agent-to-agent payment flows.
